# Cloud Native To-Do App

A hands-on cloud-native project for learning Docker, Terraform, GitHub Actions, Azure, Checkov, and Dapr.

## Stack

- Python + FastAPI
- Docker
- Azure Container Apps
- Terraform
- GitHub Actions
- Checkov
- Dapr

## Phases

1. Project foundation
2. Local API service
3. Frontend
4. Dockerization
5. Local multi-service development
6. Terraform Azure foundation
7. Azure Container Apps deployment
8. CI/CD with GitHub Actions
9. Security scanning with Checkov
10. Dapr integration
11. Observability and hardening
